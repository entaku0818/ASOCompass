## 結論（要旨）

**前回の是正2件はどちらも実施済みで、正しく効いている。にもかかわらず「ボイスメモ」は 67位 → 159位 と更に倍以上悪化した。**
原因は前回の主因（メタデータ巻き戻し）ではなく、**競合が同じキーワードのタイトルに乗り換えてきたこと**に入れ替わっている。

前回推奨した対策の実施状況:

| 前回の推奨 | 実施状況 |
|---|---|
| ① ASCメタデータを復元し、リポジトリと一元化する | **✅ 実施済み**（2026-07-04, VoiceMemo `39d0ce7f`）。現在ストア上のタイトルは『シンプル録音 - AI文字起こし&ボイスメモ』で、`fastlane/metadata/ja/` の name/subtitle/keywords とも一致 |
| ② リリースレーンからメタデータ上書きを分離する | **✅ 実施済み**。`fastlane/Fastfile` のリリース系3レーンはすべて `skip_metadata: true`、`skip_metadata: false` は専用レーン（123行目）のみ |
| ③ 勝てるキーワードへの再配分・レビュー基盤強化 | 部分的。keywords.txt は再構成済み。レビュー数は 193件 → 206件（2ヶ月で +13件）で、増加ペースは変わっていない |

つまり**「直したのに戻らなかった」のではなく、「直したうえで別の要因に負けている」**状態。

## 2. なぜ頭部2語だけ落ち続けたのか

### 2-1. 競合が「同じタイトル構成」に乗り換えた

7/4時点の Studio Zebra のタイトルは『ボイスレコーダー』系だったが、**現在は
『ボイスレコーダー - AI文字起こし＆ボイスメモ録音アプリ』**に変わっている。

これは復元後のシンプル録音のタイトル『シンプル録音 - AI文字起こし&ボイスメモ』と
**ほぼ同一のキーワード構成**であり、レビュー数は 37,988件（シンプル録音の 184倍）。
同じ土俵で殴り合う形になり、評価数の差がそのまま順位差として出ている。

### 2-2. 完全一致タイトルが上位を占める構造

「ボイスメモ」上位10件（2026-09-10 実測）:

| 順位 | アプリ | 評価 | 評価数 |
|---:|---|---:|---:|
| 1 | ボイスメモ（Apple公式） | 4.62 | 200,609 |
| 2 | ボイスメモ ・ ボイスレコーダー | 3.67 | **3** |
| 3 | PCM録音 | 4.58 | 71,922 |
| 4 | ボイスレコーダー - AI文字起こし＆ボイスメモ録音アプリ | 4.42 | 37,988 |
| 5 | Notta | 4.35 | 26,568 |
| 7 | ボイスレコーダー - 録音アプリ & ボイスメモ | 4.42 | 4,999 |
| 8 | ボイスメモ・録音・文字起こし: Spiik | 4.35 | 976 |
| … | **シンプル録音** | 4.19 | 206 → **159位** |

**評価3件のアプリが2位に入っている**点が重要で、この検索語では
「タイトルが検索語で始まるか」が評価数より強く効いている。
シンプル録音はブランド語「シンプル録音」が先頭で、検索語はハイフン以降にあるため構造的に不利。
（「ボイスレコーダー」でも同様に、評価118件のアプリが4位、シンプル録音は112位）

## 4. 改善アクション（優先度順）

### ① 頭部2語（ボイスメモ／ボイスレコーダー）の正面突破をやめる

- 評価200,609件のApple公式 + 37,988件の同一構成競合がいる土俵で、206件で勝つ設計にはなっていない。
- タイトルからこの2語を外す判断は**慎重に**。外すと現在の11位（録音）・11位（録音アプリ）にも影響し得るため、
  変更するなら**1要素ずつ・2〜3週の観測期間を置いて**行うこと（前回の教訓）。

### ② すでに上位30位圏にいる中尾キーワードをtop10に押し上げる

現在の実測で **会議録音 24位 / 講義録音 26位 / 議事録 40位 / 音声録音 42位**。
いずれも上位勢の評価数が頭部語ほど極端でなく、**サブタイトルでの複合語強化で10位圏が狙える**。
サブタイトル『高音質録音・会議議事録・講義録音』は既にこの方向なので、
keywords.txt 側で頭部語との重複（現在1語目が「ボイスレコーダー」）を削り、中尾語に枠を再配分する。

### ③ 表示→PV 率 4.3% の改善（アイコン・スクショ1枚目）

CVR 49%が示すとおり中身は勝てている。検索結果の一覧で選ばれていないだけなので、
**アイコンと1枚目のスクショのA/Bテスト（Product Page Optimization）**が最も費用対効果が高い。

### ④ レビュー獲得ペースの引き上げ（前回③の再掲・未着手）

2ヶ月で+13件では、順位防御力は上がらない。前回同様、文字起こし成功直後などの
満足度が高い瞬間にプロンプトを出す設計への変更を推奨。

## 付録: 測定方法

順位は iTunes Search API の結果配列内での自アプリ（bundleId = com.entaku.VoiLog）の位置。

```bash
curl -s "https://itunes.apple.com/search?term=<キーワード>&country=jp&media=software&entity=software&limit=200" \
  | python3 -c "import sys,json;print([i+1 for i,a in enumerate(json.load(sys.stdin)['results']) if a.get('bundleId')=='com.entaku.VoiLog'])"
```

返却件数は語によって163〜194件で200に満たないため、「圏外」は概ね*返却された全件に入っていない*の意。
ASO-tool 本体（`POST /apps/{id}/scrape/rankings`）を使えば履歴として蓄積できる。
